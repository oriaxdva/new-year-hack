| 1 | FLAG{HTML_C0MMENT_2027} | комментарий в исходниках index.html |

| 7 | ??? | секрет. в списке зада­ний значится вопросом, на стене не упоминается. ввод в консоль ЛЮБЫХ символов в любом количестве забирает его (ловушка: ошибка в консоли или вызов console.*). |

Итоговый финал — при всех 7 флагах: баннер с кнопкой «ЗАКРЫТЬ» и конфетти.

## Быстрый тест финала

```js
localStorage.setItem('hu_flags', JSON.stringify([
 'FLAG{HTML_C0MMENT_2027}','FLAG{C0NS0LE_HUNT_2027}','FLAG{2027_HAPPY_HACKERS}',
 'FLAG{ADMIN_PANEL_H4CKED}','FLAG{IDOR_N0TES_2027}','FLAG{R0LE_SW4P_2027}',
 'FLAG{GHOST_INPUT_2027}']));
location.reload();
```

Сброс квеста: `localStorage.clear()` и перезагрузка (потребуется снова ввести код доступа).

## Тест флага №7

Открыть консоль (F12) и ввести любую строку, например `asdasd` — ReferenceError выдаст
флаг `FLAG{GHOST_INPUT_2027}`. Либо любая строка через `console.log('...')`.
Ловушка активируется через 4 секунды после загрузки, чтобы не ловить шум самой страницы.
