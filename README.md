# HACKER UNION :: 2027 — новогодний квест

## Флаги (для организатора, участникам не показывать!)

| # | Флаг | Где спрятан |
|---|------|-------------|
| 1 | `FLAG{HTML_C0MMENT_2027}` | HTML-комментарий в `index.html`, сразу после `<body>` |
| 2 | `FLAG{C0NS0LE_HUNT_2027}` | Печатается в консоль браузера (F12) |
| 3 | `FLAG{2027_HAPPY_HACKERS}` | В конце трансляции президента (сдаётся автоматически) |
| 4 | `FLAG{ADMIN_PANEL_H4CKED}` | Вход в админку: путь в `robots.txt`, пароль `M4ND4R1N2027` в комментарии `admin-login.html` |
| 5 | `FLAG{IDOR_N0TES_2027}` | Служебная заметка id=3 в админке |
| 6 | `FLAG{R0LE_SW4P_2027}` | Хранилище в админке: «сервер» хранит роль в `localStorage` (`hu_role=guest`). Решение: `localStorage.setItem('hu_role','admin')` и перезагрузка |

## Файлы

- `index.html` — главная страница
- `crt.css` — общий стиль (зелёный CRT)
- `admin.css` — стиль админки (янтарная тема), подключается вторым
- `app.js` — метель, печать, звук, флаги, часы
- `admin-login.html` / `admin.html` — админка
- `robots.txt` — подсказка про админку

## Механика

- Счётчик флагов хранится в `localStorage` (ключ `hu_flags`), прогресс не сбрасывается при перезагрузке.
- Флаги принимаются в любом регистре.
- Роль в админке хранится в `localStorage` под ключом `hu_role` — это и есть уязвимость №6.
