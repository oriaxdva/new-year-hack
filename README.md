# HU::2027 // BLACK TEAM — карта флагов (только для автора)

Новогодний веб-квест: 8 флагов, от простых к сложным. Все флаги можно сдавать в терминале (`submit FLAG{...}`) или они сдаются автоматически.

## Флаги по возрастанию сложности

1. `FLAG{W3LC0ME_2027}` — HTML-комментарий в исходнике главной страницы (Ctrl+U). Сдается автоматически при первом визите.
2. `FLAG{C0NS0LE_D1VER}` — открыть консоль (F12), прочитать приветствие.
3. `FLAG{NEW_YEAR_ADDR3SS}` — досмотреть «Обращение» до конца (печатается по буквам), сдается автоматически.
4. `FLAG{ADMIN_PANEL_H4CKED}` — robots.txt намекает на /admin-login.html, пароль M4ND4R1N2027 спрятан в HTML-комментарии страницы входа.
5. `FLAG{1DOR_N0T3S}` — IDOR: в админке в URL дописать ?note=3 (в списке показаны только заметки 1 и 2).
6. `FLAG{R0LE_SW4P_2027}` — broken access control: в консоли `localStorage.setItem('hu_role','admin')`, обновить страницу админки.
7. `FLAG{TERMIN4L_CHE4T_2027}` — в терминале ввести `whoami --force-admin` (легче шестого).
8. `FLAG{S4F3_N0T_L0CK3D}` — резервный код: в localStorage лежит `backup_pin` (ROT-3, каждый символ +3). Декодировать в консоли, получить ARCHIVE_CODE_2027, ввести в разделе «Резервный код» админки.

## Финал

После сбора всех 8 флагов на главной странице появляется баннер «С Новым годом, Black Team!» и конфетти. Баннер сохраняется в localStorage.

## Стена сообщений

Подсказки-посты (n0ctis, unknown, phantom_404) лежат в WALL_HINTS, живая лента — в WALL_ALIVE в app.js. Живые посты появляются каждые 20 секунд, висят 12 секунд. Проверить: команда `wall chat` в терминале.
