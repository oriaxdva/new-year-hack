# HU::2027 · BLACK TEAM

Новогодний хакер-квест: сайт-терминал с CRT-атмосферой, обращением президента
хакеров и шестью спрятанными флагами. Статика для GitHub Pages — сервер не нужен.

## Файлы

| Файл | Что это |
|---|---|
| index.html | Главная: брифинг, обращение, задания, стена, терминал |
| crt.css | Праздничная CRT-тема (мягкий фосфор, гирлянда, снег) |
| app.js | Движок: снег, гирлянда, печать обращения, флаги, терминал |
| admin-login.html | Вход в админку (пароль спрятан в комментарии) |
| admin.html | Админка: заметки с IDOR + хранилище с проверкой роли |
| admin.css | Янтарная «секретная» тема штаба |
| robots.txt | Намёк на запасной вход |

## Карта флагов (для организатора — игрокам не показывать!)

1. `FLAG{HTML_C0MMENT_2027}` — комментарий в исходнике index.html сразу после `<body>`.
2. `FLAG{C0NS0LE_HUNT_2027}` — печатается в консоль браузера (F12) через 2 секунды.
3. `FLAG{2027_HAPPY_HACKERS}` — полностью досмотренная трансляция (сдаётся автоматически).
4. `FLAG{ADMIN_PANEL_H4CKED}` — путь: robots.txt → admin-login.html → пароль `M4ND4R1N2027`
   из комментария в исходнике страницы входа. Вводится вручную на странице ЗАДАНИЯ.
5. `FLAG{IDOR_N0TES_2027}` — в админке открыть заметку id=3 (сдаётся автоматически).
6. `FLAG{R0LE_SW4P_2027}` — в админке: консоль →
   `localStorage.setItem('hu_role','admin')` → обновить страницу (сдаётся автоматически).

Прогресс хранится в `localStorage` (ключ `hu_flags`), флаги принимаются в любом регистре.

## Публикация

GitHub Pages: Settings → Pages → ветка main → Save. После каждого коммита ждать 1–2 минуты.
